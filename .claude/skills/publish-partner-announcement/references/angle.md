# Step 2 — Angle

State what the announcement means **commercially for the Mexican market**.
Relaying the release is not the product.

## Ask, in order

1. **What changes?** Money, distribution, category exclusivity, market
   access, valuation signal. If nothing changes, there is no story.
2. **Who else is affected?** Competitors in the category, the property's
   other partners, the rest of the market.
3. **What does it signal about the property's commercial direction?** A
   licensing deal with limited initial production says something specific
   about where the property thinks it is: testing demand, not banking on it.
4. **Is this a first?** First in category, first foreign brand, first
   licensing structure of its kind — verifiable firsts only.

## If there is no angle, say so

Recommend the shorter format and move on:

- **Social only** — logo-swap or undisclosed-terms partner news.
- **Newsletter brief** — a line in a roundup.
- **Full portal article** — only with a real mechanism (step 7's test).

Recommending down is a correct outcome. Manufacturing significance to
justify a longer format is not.
