# Step 1 — Intake gate

A hub is a standing promise to keep covering something. Do not make it
lightly: a destination page nobody feeds is worse than no page.

## Answer these before any code

1. **Property and full commercial name.** Check for a title sponsor — the
   LFA trades as *LFA FINSUS*. That is a naming-rights fact and therefore
   already a Playbook story.
2. **Why permanent?** A hub earns its route when the property will generate
   recurring BUSINESS news — capital, expansion, rights, sponsorship — not
   just results. If the honest answer is "one big story", use a tag.
3. **Commercial thesis, one sentence.** Why does a sports-business reader
   open this instead of a scores site? If you can't write it, the hub isn't
   ready.
4. **Out of scope.** List the adjacent properties that will generate near
   misses. These become the boundary table in step 2.
5. **Who feeds it?** Which products cover this beat (`relatedSources`)?

## Rejection is a valid outcome

Recommend a tag-only treatment when: the pool is empty AND no editorial
commitment exists to fill it; or the property is a one-off event already
served by an existing product; or the "thesis" is really just fandom.

Say so plainly. An unfed hub costs more credibility than it earns.
